## Metis Rise — Agent Builder Program

- **Portal:** https://www.metis.io/agent-builder-program  · **Announced:** Oct 2026 · **Chain:** Metis Andromeda
- **The pitch (verbatim, from Metis's own indexed copies):** *"AI agents are everywhere. Very few earn a living.
  Metis has officially launched the Metis Rise Agent Builder Program, rewarding new agents on the Andromeda
  Mainnet who bring real users and real on-chain activity."* · *"Build AI agents on Metis Andromeda, grow real
  usage, and compete for **$1,500 in monthly rewards**."* · *"Not another demo. Not another idle contract."*
- **Judged on:** real users + on-chain traction — **not demos.** (Same standard as Metis's summer 2026 8-week
  builder program run with ClawUp, GOAT Network, LazAI, CryptoChicks and MindFuel: 91 applicants → 12 teams →
  9 finalists.)
- **Our fit:** 🔥🔥 x402 + ERC-8004 + real on-chain agent activity is exactly the judged criterion. The vault
  already rates this ecosystem highest-leverage — the July scan logged *"Metis OpenClaw Builder Bootcamp — $5k +
  GOAT grant pipeline — x402 + ERC-8004 — our stack. Stage 2 feeds GOAT $1M"*, and GOAT's builder program is
  **backed by GOAT Network, Metis L2, ClawUp AI**.
- **Honest cost:** Metis **Andromeda is a new rail** for us (we run Avalanche / Base / Solana). Our x402 gateway
  and ERC-8004 registration port, but the agent has to actually exist and transact on Andromeda.
- **The real value is not the $1,500/month** — it's that the criterion forces us to produce the one thing our own
  record says we lack: users and on-chain activity. Consistent with the older finding that *"the constraint isn't
  agents, it's work."*
